# Livraria Marginália — V1 (linha de base)

Amostra criada pelo grupo com apoio de IA (Claude) para o trabalho de PageSpeed Insights (Trilha I).
Livros, autores, preços e capas são fictícios.

## Páginas (fluxo do usuário)
1. `index.html` — Início e catálogo
2. `produto.html?id=1` — Página do livro
3. `carrinho.html` — Carrinho e resumo do pedido

Tarefa principal: encontrar um livro, adicioná-lo ao carrinho e conferir o total.

## Como publicar no GitHub Pages
1. Crie um repositório público novo.
2. Suba TODO o conteúdo desta pasta na raiz (index.html deve ficar na raiz, e a pasta `images/` junto).
3. Settings > Pages > Branch `main` / `root` > Save.
4. Aguarde 1–2 minutos e use o link https://SEUUSUARIO.github.io/NOME-DO-REPO/ no PageSpeed Insights.

## Importante para o trabalho
- Guarde uma cópia desta pasta como **V1** antes de qualquer alteração.
- Faça as melhorias em outra cópia/branch (**V2**).
- Não apague conteúdo nem funcionalidades para aumentar a nota.
